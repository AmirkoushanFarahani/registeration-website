# سامانه ثبت‌نام دانش‌آموزان ایران

نسخه اولیه رابط کاربری پیش‌ثبت‌نام دانش‌آموزان، به زبان فارسی و راست‌به‌چپ.

## اجرا

فایل `index.html` را در مرورگر باز کنید. این نسخه کاملاً سمت کاربر است و اطلاعات را به سرور ارسال نمی‌کند.

## گام بعدی پیشنهادی

برای استفاده واقعی، یک بک‌اند امن برای احراز هویت، ذخیره‌سازی رمزنگاری‌شده اطلاعات هویتی، پیگیری درخواست و پنل مدیر لازم است.
